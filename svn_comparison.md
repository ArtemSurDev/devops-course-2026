# Сравнение Git и SVN

## 1. Почему в Git ветвление дешёвое, а в SVN дорогое?

В Git ветка — это просто указатель на коммит, создаётся мгновенно. В SVN ветка — копирование директорий на сервере, операция медленная и тяжёлая.

## 2. Можно ли в SVN сделать коммит без интернета?

Нет. SVN централизованная, все коммиты идут на сервер. Без подключения коммит невозможен.

## 3. В каких сценариях SVN предпочтительнее Git?

В legacy-проектах, где SVN уже используется. В организациях с жёсткой централизацией. В госсекторе и банках, где важна простота и предсказуемость.
